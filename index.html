Tiga fase yang perlu dikuasai

Kesiapsiagaan bukan satu tindakan, melainkan rangkaian keputusan kecil di tiga waktu yang berbeda.

Sebelum Gempa

  • Kenali jalur keluar
    Petakan dua jalur berbeda dari rumah dan tempat kerja.
  • Siapkan tas siaga
    Air, obat pribadi, senter, salinan dokumen penting.
  • Amankan perabot berat
    Kunci lemari dan rak ke dinding.

Saat Gempa

  • Jatuhkan diri
    Turun ke lantai sebelum kehilangan keseimbangan.
  • Lindungi kepala
    Berlindung di bawah meja kokoh, tutup kepala dan leher.
  • Bertahan di tempat
    Tetap berlindung sampai guncangan berhenti.

Setelah Gempa

  • Waspadai tsunami
    Gempa kuat di pesisir — segera ke dataran tinggi.
  • Periksa sekitar
    Cek kebocoran gas dan kabel sebelum menyalakan apa pun.
  • Ikuti titik kumpul
    Tunggu informasi resmi dari petugas.

Tata Cara Pasang Aplikasi

Pilih perangkat Anda untuk melihat panduan instalasi langkah demi langkah:

1
Buka di Google Chrome atau Samsung Internet

Pastikan Anda membuka website ini melalui browser Google Chrome di ponsel Android Anda.

2
Ketuk Menu Titik Tiga (⋮) di Pojok Kanan Atas

Buka menu opsi peramban yang berada di sudut kanan atas layar.

3
Pilih "Instal Aplikasi" atau "Tambahkan ke Layar Utama"

Atau Anda juga dapat langsung menekan tombol putih "+ Pasang sebagai Aplikasi" di halaman ini.

4
Ketuk "Instal" pada Dialog Konfirmasi

Aplikasi akan otomatis terpasang di HP Anda layaknya file APK native, dan tombol pasang di web akan otomatis hilang!

1
Buka di Google Chrome atau Microsoft Edge

Gunakan browser modern di Windows atau Linux.

2
Klik Ikon "Instal" di Address Bar

Perhatikan sisi kanan kolom URL (di samping ikon bintang bookmark), akan muncul ikon komputer kecil dengan tanda panah ke bawah bertuliskan "Instal Siaga Gempa".

3
Atau via Menu Browser (⋮)

Pilih menu browser -> "Simpan dan bagikan" -> "Instal Siaga Gempa".

4
Aplikasi Terbuka di Jendela Mandiri

Aplikasi dapat diakses langsung dari Desktop atau Start Menu tanpa membuka browser terlebih dahulu.

1
Tablet Android

Buka Chrome di tablet Anda -> ketuk menu titik tiga (⋮) -> pilih "Instal Aplikasi".

2
Apple iPad (iPadOS)

Buka situs di Safari -> ketuk ikon Share / Bagikan (kotak berpanah ke atas di bagian atas) -> gulir ke bawah lalu ketuk "Tambah ke Layar Utama" (Add to Home Screen) -> ketuk Tambah.

1
Buka Website di Peramban Safari

Apple mewajibkan penggunaan browser Safari untuk memasang aplikasi PWA ke layar utama iPhone.

2
Ketuk Tombol "Bagikan" (Share)

Ikon kotak dengan tanda panah ke atas yang terletak di bilah navigasi bawah layar iPhone.

3
Pilih "Tambah ke Layar Utama" (Add to Home Screen)

Gulir menu tindakan ke bawah dan ketuk opsi Tambah ke Layar Utama.

4
Ketuk "Tambah" (Add) di Pojok Kanan Atas

Ikon Siaga Gempa kini muncul di Home Screen iPhone Anda dan siap dibuka dalam mode fullscreen tanpa browser bar.

1
Safari di macOS Sonoma (14.0+) atau Lebih Baru

Buka Safari -> klik menu File di bilah menu paling atas Mac -> pilih "Tambahkan ke Dock..." (Add to Dock...) -> klik Tambah.

2
Google Chrome di Mac

Buka situs di Chrome -> klik ikon instal di sebelah kanan kolom URL atau pilih menu titik tiga -> "Instal Siaga Gempa".

💡 Catatan: Setelah terpasang di HP atau laptop, tombol "Pasang Aplikasi" di web ini akan otomatis disembunyikan karena aplikasi sudah berjalan secara mandiri dari layar utama perangkat Anda.
